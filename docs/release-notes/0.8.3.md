## A proxy for sync, AI and updates

**Settings → Proxies** has a new **Proxy for Hatoba** setting for this device: **System proxy**, the default, or one of your saved proxies. Sync, the AI assistant (its providers, web search, the pages it reads, ChatGPT sign-in and HTTP MCP servers) and update checks go through it. Until now they used only the system proxy, which on Linux meant only the proxy environment variables, so an app opened from the desktop behind a system proxy such as Clash's stayed offline. Addresses on this computer connect directly, and a SOCKS5 proxy looks up host names itself, as it does for SSH hosts. A change applies right away, while MCP servers that are already connected keep their connection until they restart.

**Port Forwarding** is now a list like the hosts and keys lists. Each rule shows whether it runs, where it listens or why it failed, with **Start**, **Stop** or **Retry** beside it, and its right-click menu and the arrow keys work as on the hosts page. **Start on connect** is a column of the list, and Escape closes the forward dialog also while a field has focus.

The assistant's replies highlight code blocks and draw tables with a line between rows, and **Settings → AI** shows each provider's logo. **Cloud Sync** opens with the same page header as the other pages, with **Sync Now** in it. SFTP shows files with icons by type, and empty pages break Chinese and Japanese lines only between words.

The update notes in **Settings → About** fold the smaller changes under **Other changes** instead of showing HTML tags. On the hosts page, the selection box stays inside the list, so dragging past its edges no longer makes the list grow and scroll on and on.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
