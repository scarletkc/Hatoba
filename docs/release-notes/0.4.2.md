## Reordering tabs, and well-known models behind gateways

New since 0.4.1:

- **Reordering tabs**: drag a tab along the tab bar to move it, as in a browser. Esc puts it back, the home tab stays first, and Ctrl+Tab (⌃Tab on macOS) follows the new order.
- **Well-known models behind gateways**: when a provider such as New API lists only model ids, Hatoba fills in the context window and output limit of well-known Claude, GPT, Gemini, DeepSeek, and Qwen models, so **Context usage** shows how full the conversation is and long conversations are compacted automatically. Their thinking levels, adaptive thinking included, are filled in too when the provider uses the model vendor's own protocol. What you enter under **Settings → AI → Providers** still comes first.
- **Pressing keys**: the assistant can press keys in order after what it types, such as Ctrl+X and then N to leave nano without saving, or Esc, `:wq`, and Enter to save and quit vim. The approval card lists the keys after **Then press**, and **Edit** adds or removes them. **Auto** checks keys pressed one by one as it checks typed text, so a command spelled out key by key still asks first.
- **Memory dates**: each memory carries the day it was last saved, so the assistant can tell an old note from a recent one and prefers the newer of two that disagree.

A master password needs 8 characters again, not 12. **Change Master Password** on the sync page now opens the same dialog as Settings, with the strength meter and its warning for a password that is easy to guess.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
