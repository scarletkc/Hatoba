## One hosts page, zoom, and resource usage of macOS servers

New since 0.6.0:

- **A navigation rail instead of the sidebar**: the home tab, the house at the start of the tab bar, has a rail with **Hosts**, **Forwards**, **Keys**, and **Sync**, whose icon shows the sync status. Terminal tabs have no rail, so a terminal gets the window's whole width. The tab bar spans the window, with the lock and the Settings gear beside the AI button.
- **One hosts page**: the host list and the dashboard are now one page. Group buttons above the hosts open a group, **Favorites** and **Tags** narrow the list to the hosts with every tag you pick, and **New Group** is under the arrow beside **New Host**. Hosts show as a **List** or as **Cards**, and **Resource Usage** reads the CPU, memory, disk, and network of the listed hosts as the dashboard did, with the dashboard's sort orders and, in the list, its **Columns** menu. Each device keeps both choices, and the page starts as a list without resource usage. Double-click or Enter connects, and **Show Details** or Space opens a host's readings. Hosts you left out of the dashboard stay unread, and **Read Usage** in their menu brings them back. The list is sorted by **Recent** to begin with, so there is no separate Recent view.
- **Zoom**: Ctrl+= and Ctrl+- (⌘ on macOS) make what has focus larger or smaller, and Ctrl+0 brings it back to its default size. In a terminal they change the font size of every terminal tab, and so does Ctrl+wheel over a terminal, even while a program there reads the mouse. In the AI panel they change the size of the conversation, the input, and approval cards, which **Settings → Appearance → AI Panel → Text Size** sets too. Anywhere else they zoom the whole window, from 67% to as much as 200% where the screen has room, which **Settings → Appearance → Zoom** sets for this device. Ctrl+wheel and touchpad pinches change nothing but a terminal's font, so a stray one never zooms the window.
- **Resource usage of macOS servers**: the terminal's status bar and the hosts page show the resource usage of macOS servers as they do for Linux servers. Memory in use is counted as Activity Monitor counts it, and the disks are `/` and the volumes Finder shows, each APFS container once.
- **Names for forwarding rules**: a rule's dialog starts with an optional **Name**, such as Postgres. The Port Forwarding page and the terminal's status bar show the name first, with the rule beside it, and the tray menu lists the forward as `host · name`.
- **Settings grouped by what they shape**: **Terminal** has everything about the terminal, its colors, right-click, and multi-line paste check included, over one preview in the chosen color scheme. **Appearance** has the theme, list density, zoom, and the AI panel's text size, and **Language** is at the top of **General**. General, Terminal, and Security are split into titled sections.

While a reply waits for the model, or the model thinks, its status is the reply's first line, where its text will start, so the reply no longer jumps when it arrives. A menu's highlight leaves with the pointer, the arrow keys skip disabled items, and ↑ with nothing highlighted goes to the last item. Selected tabs, the pressed SFTP button, and chosen options keep their width, so what's beside them no longer shifts.

Update Hatoba on every device that syncs your vault: an older version doesn't show a rule's name, and editing the rule there removes it. Changing a synced setting there, such as the terminal font, also sets the AI panel's text size back to its default.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
