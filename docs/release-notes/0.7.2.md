## Traditional Chinese

Hatoba is now in Traditional Chinese, worded as in Taiwan. It starts in Traditional Chinese when the system language is Chinese for Taiwan, Hong Kong, or Macau, and **Settings → General → Language** offers **繁體中文** on any system. Its text uses Microsoft JhengHei UI on Windows and PingFang TC on macOS, copies that a sync conflict keeps end in 「（衝突副本）」, and the assistant names buttons and settings as they read in Traditional Chinese. The website has Traditional Chinese pages at [hatoba.fog.moe/zh-tw](https://hatoba.fog.moe/zh-tw/), where browsers set to Traditional Chinese land, and with this release the demo there is in Traditional Chinese too.

The arrow beside **New Tab** stays highlighted while its menu is open, like the other menu buttons.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
