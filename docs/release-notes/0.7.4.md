## Lock screen fix for SFTP

While Hatoba was locked with a session still connected, a file dragged onto the window could upload into the folder open in that tab's SFTP panel. Now nothing reaches a server from behind the lock screen: SFTP actions, file drops, and resource usage readings wait until you unlock. Transfers that started before the lock still finish.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
