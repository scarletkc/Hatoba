## First alpha

This is the first preview of Hatoba, a desktop SSH client with an AI assistant and end-to-end encrypted sync through your own Cloudflare account. It runs on Windows 10 and 11. Expect rough edges, and keep a backup of anything you cannot lose: an alpha can still change how data is stored.

What you can try:

- **Hosts and terminal**: groups, tags, search, `~/.ssh/config` import, ProxyJump, tabs, CJK input methods, terminal search, and clickable links.
- **Authentication and keys**: passwords, Ed25519, ECDSA, and RSA keys, ssh-agent, keyboard-interactive (2FA), and a key vault that imports OpenSSH, PEM, and PuTTY `.ppk` keys.
- **SFTP and port forwarding**: a file panel beside the terminal, and local forwards that can start with the connection.
- **Vault**: a master password with a recovery code, auto-lock, and encrypted backups.
- **Cloud sync**: deploy the sync Worker to your Cloudflare account from the app, then sync your devices through it.
- **AI assistant**: a panel beside each terminal that reads the screen and runs commands with your approval, using your own OpenAI-compatible or Anthropic API key, with skills and MCP servers.

If you forget the master password and lose the recovery code, your data cannot be recovered. Report problems with **Settings → About → Report a Problem**.
