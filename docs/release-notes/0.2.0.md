## Dashboard and the hatoba command

New since 0.1.0:

- **Dashboard**: the online status, CPU, memory, disks, network, load, and uptime of every saved host on one page, as cards or a table, read over SSH with nothing to install on the servers. Open a host for its CPU and network over the last few minutes, and set the warning thresholds and how often it refreshes in **Settings → General**.
- **The `hatoba` command**: turn on **Settings → General → Use the hatoba command in terminals**, then run `hatoba <host name>` or `hatoba user@host` in any terminal to connect in Hatoba.
- **`/` commands and `@` mentions**: in the AI panel, type `/` to run a command, a skill, or an MCP prompt, and `@` to attach a file or folder on the host, or an MCP resource.
- **Conversations keep running**: starting a new conversation or opening another one no longer stops the assistant. History marks the conversations that are still working or waiting for your approval.
- **Faster tools**: the assistant runs calls that only read at the same time, and its file search uses `rg` where the host has it.
- **Stopping a command**: when you stop the assistant or a command times out, Hatoba ends the command on the server where it can, and tells the assistant whether it ended or may still be running.

The new [website](https://hatoba.fog.moe) has the downloads and the user documentation.

0.1.0 updates to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
