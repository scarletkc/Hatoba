## Selecting several hosts

On the hosts page, Ctrl+click (⌘-click on macOS), Shift+click, Shift with the arrow keys, and Ctrl+A (⌘A) select several hosts, in the list and in the cards. Enter connects each of them in a tab of its own, one after another, and Delete (⌘⌫) deletes them after asking once for all of them. Right-clicking one of them shows **Connect**, **Add to Favorites** (or **Remove from Favorites** when all of them are favorites), and **Delete**. Right-clicking a host outside the selection selects it alone and shows its usual menu. Hosts that a filter or a search hides leave the selection, so nothing acts on a host you can't see.

The list no longer keeps a host selected on its own: a click beside the hosts or Esc selects none. A search still selects its best match, so typing a name and pressing Enter still connects.

The tag filter chips have their × inside the tag, as in the host editor, and only the × removes a tag. The **Tags** button no longer shows how many tags are picked, and stays blue while some are. Buttons and menu items, such as **Delete** and **Upload Files**, no longer end with an ellipsis.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
