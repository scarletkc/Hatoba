## Sign in with ChatGPT, PIN unlock, and the tray

New since 0.2.0:

- **Sign in with ChatGPT**: choose **Continue with ChatGPT** in **Settings → AI** to use your ChatGPT plan with the assistant. The provider syncs to your other devices, where you sign in once more.
- **OpenAI Responses**: providers can use the OpenAI Responses protocol. New providers for `api.openai.com` use it, and existing providers keep theirs.
- **Search with the model's provider**: without a search provider chosen, the assistant searches the web with the current model's provider, shown as **Native Search** in **Settings → AI**. Choose **None** to turn web search off.
- **Main content of web pages**: when the assistant reads a page, it gets the main content without the navigation, sidebars, and footers, unless it asks for the whole page.
- **Notifications**: while Hatoba isn't the active window, a system notification tells you when an AI conversation finishes or waits for your approval. Click it to go back to the conversation, or turn it off in **Settings → General**.
- **Minimize to the tray** (Windows and Linux): the close button asks whether to quit or to minimize Hatoba to the system tray, where SSH sessions, port forwards, and sync keep running. **Settings → General → Close Button** changes the answer. On Linux desktops without a tray, such as GNOME without an extension, the close button quits as before.
- **PIN unlock**: turn on **Settings → Security → Unlock with PIN** to unlock with a PIN after the first unlock of each launch. Five wrong PINs in a row turn it off until you unlock with the master password, a recovery code, or Windows Hello.
- **Windows Hello on its own**: the lock screen shows the Windows Hello prompt as soon as you come back to Hatoba.
- **Daily update check**: Hatoba checks for updates every day while it runs, and the tray menu offers a new version when there is one.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
