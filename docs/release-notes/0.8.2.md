## Box selection and a custom order for hosts

On the hosts page, dragging from beside the hosts draws a box that selects the hosts it touches. Hold Shift to add them to the selection, or Ctrl (⌘ on macOS) to switch them in or out of it. Dragging a host, or several selected hosts, moves them to where you let go, and Alt+↑/↓ (⌥↑/↓ on macOS) moves the selected hosts one place. The page then sorts by the new **Custom** order, which starts from the order the page showed and syncs to your other devices. Escape ends a box or a drag without a change. The hosts page also keeps its sort order after a restart.

The keys list now works like the hosts list. ↑/↓ select a key, also from the search box, and typing in the list searches. Delete (⌘⌫ on macOS) deletes the selected key after asking, and a key's right-click menu has **Rename**, **Deploy to Host**, **Copy Public Key** and **Delete**. The arrow keys no longer draw a focus ring around the selected key.

The wording across the app is more consistent in English, Chinese and Japanese.

Older versions don't show the custom order, and a host changed on one of them moves to the end of it.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
