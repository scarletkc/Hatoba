## Local terminals, memory, and terminal color schemes

New since 0.3.0:

- **Local terminals**: open a shell on this computer in a tab, from **New Local Terminal** beside **New Tab** or with Ctrl+Shift+\` (⌃⇧\` on macOS). On Windows that is PowerShell, Command Prompt, Git Bash, or a WSL distribution; on macOS and Linux, the shells the system lists. **Settings → Terminal → Local Terminal Shell** chooses the one the shortcut opens.
- **The assistant in local tabs**: it runs commands and reads, edits, and searches files on this computer as it does on a host, with the same approvals. In PowerShell and Command Prompt tabs it reads commands in their own syntax, so commands that only read, such as `Get-ChildItem` or `ipconfig`, run without asking.
- **Memory**: the assistant saves what will help later, such as your preferences and facts about your hosts, and every new conversation starts with it. Memories sync with your vault. **Settings → AI → Memory**, also opened by `/memory`, lists them, lets you add, edit, and delete them, and turns memory off.
- **Terminal color schemes**: **Settings → Appearance → Terminal Colors** offers 18 built-in schemes, among them Dracula, Tokyo Night, Catppuccin, Nord, Gruvbox, Solarized, and Rosé Pine. Pick one for dark and one for light, and choose **Match Appearance** to switch between them with the app.
- **A folder for each command**: the assistant can run a command in a given folder. The approval card shows the folder, and **Edit** changes it.
- **Following replies**: the AI panel follows a reply to the bottom as it streams, and stops as soon as you scroll up.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
