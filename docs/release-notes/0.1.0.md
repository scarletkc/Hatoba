## First stable release

Hatoba is a desktop SSH client with an AI assistant and end-to-end encrypted sync through your own Cloudflare account. It runs on Windows 10 and 11 and on Linux, and an experimental build runs on Apple Silicon Macs.

- **Hosts and terminal**: groups, tags, search, `~/.ssh/config` import, ProxyJump, SOCKS5 and HTTP proxies, quick connect, tabs, CJK input methods, and server status in the status bar.
- **Authentication and keys**: passwords, Ed25519, ECDSA, and RSA keys, ssh-agent, keyboard-interactive (2FA), and a key vault that imports OpenSSH, PEM, and PuTTY `.ppk` keys.
- **SFTP and port forwarding**: a file panel beside the terminal, and local forwards that can start with the connection.
- **Vault**: a master password with a recovery code, auto-lock, and encrypted backups.
- **Cloud sync**: deploy the sync Worker to your Cloudflare account from the app, then sync your devices through it.
- **AI assistant**: a panel beside each terminal that reads the screen, runs commands, and reads and edits files on the host, with skills and MCP servers.

New since 0.1.0-alpha.2 ([all changes](https://github.com/scarletkc/Hatoba/compare/v0.1.0-alpha.2...v0.1.0)):

- **Auto mode**: a model you choose reviews the assistant's tool calls and lets the ones that are safe or that you asked for run without asking you.
- **File tools**: the assistant reads, edits, and writes files on the tab's host, shows the diff of each change, and can revert it. It also finds files and searches their contents.
- **Conversations**: queue messages while the assistant works, ask a side question without stopping it, and fork a conversation from any message.
- **MCP servers**: add GitHub, Linear, Context7, and Cloudflare from templates. Servers with many tools no longer fill the context, because the assistant looks their tools up when it needs them.
- **Cloud sync**: a device that already has a vault can join a cloud vault and bring its items along, and the **Cloud Sync** page names the items too large to sync.

0.1.0-alpha.2 updates to this version from **Settings → About**. 0.1.0-alpha.1 can't update itself, so download the installer below and run it once. The sync Worker is the same as in the alphas, so there is nothing to redeploy.

If you forget the master password and lose the recovery code, your data cannot be recovered. Report problems with **Settings → About → Report a Problem**.
