## Linux, macOS, and in-app updates

The second alpha adds Linux packages and an experimental macOS build for Apple Silicon next to the Windows installer. The maintainer uses Windows, so the Linux and macOS builds have had little testing on real machines. If something doesn't work on them, please open an issue.

0.1.0-alpha.1 can't update itself, so download the installer below and run it once. From this version on, **Settings → About** checks for updates and installs them. The sync Worker hasn't changed, so there is nothing to redeploy.

New since 0.1.0-alpha.1:

- **Quick connect**: type a target such as `user@host:port` in the hosts search field to connect without saving a host.
- **Proxies**: connect through SOCKS5 and HTTP proxies, saved in **Settings → Proxies**, with a default proxy for each device.
- **Environment variables** for each host, sent to the server before the shell starts.
- **Server status**: the CPU, memory, and network usage of Linux servers in the status bar, and an icon for each host's operating system.
- **AI assistant**: continue the home tab's conversation in a terminal tab.
- A new app icon.

This is still an alpha: keep a backup of anything you cannot lose.
