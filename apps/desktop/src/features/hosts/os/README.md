# Server OS icons

The host list and the session tabs show these logos for the operating system a server reports in its SSH identification string (HOST-11). The files are unchanged from [Simple Icons](https://simpleicons.org) 16.34.0; `OsIcon.module.css` uses them as masks and paints them with the `--os-*` colors in `src/styles/tokens.css`.

| `debian.svg` | Debian | CC-BY-SA-3.0, © Software in the Public Interest, Inc. and others ([Debian Open Use Logo](https://www.debian.org/logos/)) |
| `raspberrypi.svg` | Raspberry Pi, shown for Raspbian | CC0-1.0 (Simple Icons) |
| `freebsd.svg` | FreeBSD | CC0-1.0 (Simple Icons) |
| `netbsd.svg` | NetBSD | CC0-1.0 (Simple Icons) |

Windows uses Phosphor's `windows-logo`, because Simple Icons no longer ships Microsoft logos.
